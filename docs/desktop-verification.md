# Проверка исходного Desktop 1512

Это отчёт предыдущего этапа, до оптической коррекции десктопного масштаба.
Актуальные размеры и проверки: [Desktop Responsive Refinement](responsive-refinement.md).

- Целевая ширина: 1512 px, Chromium через Playwright.
- Скриншот: `desktop-1512.png`, production preview после загрузки шрифтов.
- Сопоставлены все секции со скриншотом исходного фрейма Figma.
- Начала секций совпадают с макетом с погрешностью менее 1 px.
  Высота страницы — 10984 px вместо 10983 px из-за округления дробных размеров.
- Горизонтальный overflow отсутствует на 1512, 1280, 1440 и 1920 px.
- 49 HTML-изображений загружены, отсутствующих ресурсов нет.
- Ermilov 700 и Onest 100–900 загружены из локальных WOFF2.
- Навигация к «О хакатоне», «Этапы» и «Партнёрам» проверена кликами.
- Временные CTA ведут к регистрации и контактам; отсутствующих якорей нет.
- Ошибок JavaScript, HTTP-ошибок и внешних запросов при загрузке нет.
- `npm run build` завершён успешно. Пути ресурсов сборки относительные.
- `git diff --check` завершён успешно. Push не выполнялся.

## Особенности сравнения

Заголовок «Что получает участник» набран Ermilov 88 px с межстрочным
интервалом 70 px вместо устаревшего шрифта исходника: сохранены две строки,
высота блока 140 px и близкая ширина. Его форма закономерно отличается.
Пиксельные номера и подписи сохранены SVG с текстом в кривых.
В отдельных SVG видны тонкие швы между соседними пиксельными фигурами,
связанные со сглаживанием браузера. Исходные векторные пути сохранены.
Кнопки с контуром используют полупрозрачную белую подложку из макета.
Планшетный и мобильный адаптив не реализованы.
