при первом открытии настроенной формы. Promise разделяется между открытиями.

## Конфигурация

Локально уже создан игнорируемый `.env.development.local` с публичными URL.
Для нового checkout:

```sh
cp .env.development.example .env.development.local
npm run dev
```

Переменные:

```dotenv
VITE_YANDEX_FORMS_ENABLED=true
VITE_YANDEX_PARTICIPANT_FORM_URL=https://forms.yandex.ru/u/6acf8895852af3fab5c7a14b?iframe=1
VITE_YANDEX_PARTNER_FORM_URL=https://forms.yandex.ru/u/6acfa04d2c4f89f2a71bb1ca?iframe=1
```

`npm run dev`: формы доступны при заданных URL, если включение не задано `false`.
Обычный production build/preview: формы отключены независимо от флага включения.
`--mode layero`: требуется явное `VITE_YANDEX_FORMS_ENABLED=true` и оба URL.
На `github.io` и `*.github.io` формы отключены также в runtime.
Workflow Pages явно очищает оба URL и устанавливает флаг `false`.
`.env.layero.example` содержит URL, но оставляет включение `false`.
Сборка с включёнными URL сама по себе ничего не публикует.
Все настройки Telegram остаются в Яндексе; секреты в VITE-переменные не добавляются.

## Ошибки и ограничения

- До iframe load отображается «Загружаем форму…» и aria-busy. Load завершает
  индикатор загрузки, но никогда не вызывает благодарность.
- При выключенном режиме или отсутствующем/невалидном URL выводится сообщение,
  внешние iframe и script не загружаются. Закрытие доступно.
- Скрипт имеет таймаут 8 секунд. Если он недоступен, iframe всё равно загружается:
  исходная высота 800 px, штатная внутренняя прокрутка и прокручиваемая оболочка.
  Поздно загрузившийся скрипт также может менять высоту.
- Через 20 секунд без load появляется сообщение с предложением закрыть окно и попробовать позже;
  оно не блокирует последующую загрузку. Обрабатывается также iframe error.
- Браузеры могут выдавать iframe load и для сетевой/HTTP-ошибки. Проверить содержание
  такого документа из родительского сайта достоверно невозможно. Кнопка закрытия
  доступна всегда; load не считается подтверждением
  доступности сервиса или отправки. Успех определяется только самой Яндекс Формой.
- Внутренние стили и служебный футер задаёт Яндекс. CSS оболочки их не скрывает,
  не обрезает и не переопределяет. Внешние запросы и аналитика внутри iframe также
  контролируются Яндексом; его служебные POST-запросы getSurvey не являются заявками в Beget.
  На 320 px одна служебная строка футера сокращается самим Яндексом; логотип,
  футер и ссылка «Пожаловаться» остаются видны. Сайт не вмешивается в эту типографику.
- Escape закрывает dialog при фокусе в родительской оболочке. При фокусе внутри
  cross-origin iframe Chrome не передаёт клавишу в родительский документ.
  Кнопка закрытия и overlay работают; Tab/Shift+Tab обрабатываются native dialog.
  Не добавлены обходы чтения DOM или перехвата клавиатуры внутри Яндекс Форм.
- При закрытии iframe удаляется, незавершённый черновик может потеряться;
  повторное открытие создаёт новую форму, как в прежнем сценарии.

Прежний `tests/frontend-api.test.mjs` сохранён как историческая проверка резервного

15 автоматизированных проверок прошли в Chrome/Playwright без новых зависимостей.
Проверены оба варианта и повторные открытия на 320 / 390 / 744 / 1512 px, все пять
CTA, соответствие URL, отсутствие дублирующих полей, авто-высота, прокрутка, закреплённое

## Перед будущим деплоем Layero

1. Получить отдельное разрешение владельца на production-деплой.
2. Проверить тексты и юридические ссылки внутри обеих Яндекс Форм, режим публикации
   и настроенные Яндексом успешные сообщения. Старые юридические документы сайта
   требуют актуализации/утверждения под действующую схему; на этом этапе их не меняли.
3. При необходимости выполнить отдельно разрешённую синтетическую отправку и проверить
   доставку в Telegram на стороне Яндекса. В этом этапе реальные формы не отправлялись.
4. Задать два публичных URL и `VITE_YANDEX_FORMS_ENABLED=true` в build-time окружении
   будущего `npm run build:layero`. Параметры Beget не включают рабочие iframe.
5. Если хостинг задаёт CSP, разрешить iframe forms.yandex.ru/cloud.yandex.ru,
   официальный script forms.yandex.ru и учесть фактические зависимости Яндекса.
6. Выпустить только статический результат Vite `dist/`; не включать серверный резерв,
   .env, служебные файлы или локальную презентацию. Проверить оба iframe на финальном
   HTTPS-домене, скролл на реальных iOS/Android и ограничения iframe при Escape.
