# Проверка окончательной редакции интерфейса, 14 октября 2026

Изменены privacy-policy.html, personal-data-consent.html, текст общего компонента обеих форм, URL двух документов и стили отступа статьи после удаления служебного предупреждения. Остальные стили, поля, кнопки, motion, валидация и backend не изменялись в этом задании. Существовавшие до задания изменения рабочей копии сохранены.

Публичные документы содержат подтверждённые ФИО/статус оператора, email, планируемый домен, даты завершения и предельного хранения, ответственного за удаление, доступ команды и ограничение будущей передачи партнёрам. TODO, предупреждение о проекте, preview и утверждения о действующей Beget/PHP/SMTP-инфраструктуре удалены. Работа иных сервисов не заявляется. Дата редакции не обозначает утверждение оператором.

Проверка выполнена в Google Chrome на локальной production-сборке, без отправки заявок и внешних интеграций:

- Обе юридические страницы и оба попапа на 1512×982, 744×1133, 390×844 — 12 представлений. Полные снимки страниц и снимки попапов рядом с этим отчётом просмотрены визуально; горизонтального переполнения документов, поверхностей попапов и текста согласия нет. Шрифты и изображения загрузились.
- В обоих типах форм один изначально пустой required-чекбокс. Заполненные имя/контакт не позволяют отправить форму без согласия. После закрытия и повторного открытия чекбокс снова пустой.
- Обе ссылки действительно открылись в отдельных вкладках, включая состояния checkbox=false и checkbox=true. Они ведут на /personal-data-consent.html и /privacy-policy.html, не переключают галочку и не вызывают submit. Обратные переходы между юридическими страницами работают.
- Ссылки подчёркнуты и используют существующий розовый цвет; hover меняет цвет на фирменный тёмный, клавиатурный focus видим. Space переключает чекбокс, Escape закрывает попап. На мобильном экране текст переносится внутри формы.
- Ноль POST-запросов, ошибок страницы и недоступных ресурсов в ходе проверки.
- npm run build и git diff --check прошли. Оба документа включены в dist; внутренняя документация docs в сборку не входит.
