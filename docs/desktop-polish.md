# Desktop Polish — 2026-10-08

Локальный заключительный проход поверх компактного Desktop. Контейнер 1200 px,
fluid typography, карточки, порядок секций, тексты, URL и исходная Hero-композиция
сохранены. Tablet 744 и Mobile 390 не реализованы.

## Внутренние отступы

Значения в CSS px; внешний ритм секций сохранён.

| Секция | Было | Стало | Дополнительная настройка |
| --- | --- | --- | --- |
| Кому подходит | сверху 64, снизу 64 | сверху 80, снизу 80 | Заголовок → карточки: 32 → 36 |
| Формат | padding shell 76 / 76 | 92 / 92 | min-height: 460 → 520; компьютер опущен на 16 px без изменения размера |
| Что получает участник | padding 0 / 0 | 24 / 32 | Заголовок → карточки: 40 → 48 |
| Заинтересовало? | padding 72 / 72 | 88 / 88 | min-height: 370 → 408; описание → кнопки: 36 → 40 |

У «Формата» учитывается абсолютная иллюстрация: реальное расстояние от её
низа до края секции при 1512 px увеличено примерно с 35 до 79 px. В контактах
min-height даёт фактическое нижнее поле около 116 px вместо 98 px.
Для блока преимуществ добавлены внутренние поля, поскольку раньше их не было;
процентное увеличение нулевого padding не применялось.

Высоты четырёх секций при 1512 px: 468 → 504, 460 → 520, 695 → 759,
370 → 408 px. Геометрия существующих pixel masks сохранена. Particles статичны;
проверка всех 48 частиц не обнаружила пересечений с текстовыми строками.

## Система состояний

`src/styles/interactions.css` подключён после композиционных стилей.
Общие токены в `tokens.css`: hover 160 ms, press 90 ms, easing
cubic-bezier(.2,.7,.2,1), lift −2 px, press +2 px.

- Основные тёмные CTA: розовая поверхность при hover, тёмная с лаймовым
  текстом при нажатии. Розовые CTA переключаются в тёмный вариант.
- Лаймовая Hero CTA: тёмная внутренняя рамка; исходная стрелка сдвигается
  на 4 px через steps(2). При нажатии стрелка смещена на 2 px.
- Outline: белая поверхность и розовый текст → розовая поверхность и белый
  текст → тёмная поверхность и белый текст. Инверсия цветов мгновенная:
  одновременная интерполяция текста и фона теряла бы контраст посередине.
  Перемещение кнопки сохраняет transition. Рамка использует прежний единый
  pixel-ring и не меняет размеры.
- Контакты: общая тёмная/лаймовая система hover и розовая/белая press.
- Навигация: рамка скрыта по умолчанию, появляется при hover/focus; keyboard
  focus дополнительно подчёркивает текст. Press возвращает тёмный текст.
- Логотипы-ссылки: небольшое изменение opacity. Skip-link имеет фокус,
  подчёркивание и состояния цвета. Native scroll region экспертов сохраняет
  клавиатурную прокрутку, получает focus и видимый тонкий scrollbar.

Все кнопки имеют внутреннюю рамку focus-visible. Использован единый контур,
без изменения layout. Для мелкого розового UI-текста и инвертированной
поверхности применяется оттенок из текущих pink/ink через color-mix (94/6).
Основные брендовые токены и цвета графики не изменены.

Контраст конечных состояний: минимум 4,69:1 для мелкого UI-текста;
для крупного жирного текста минимум 4,24:1 (требуемый порог 3:1).
Проверены computed colors в браузере; результаты в `polish/contrast.json`.

Mouse hover ограничен `(hover: hover) and (pointer: fine)`. Touch не сохраняет
мышиную заливку после касания. Reduced motion отключает transitions,
перемещения и smooth scrolling, сохраняя цветовую реакцию и focus.
13 информационных карточек статичны: у них нет ссылок, tabindex, pointer cursor
или декоративного hover. Новые JS-анимации и зависимости не добавлялись.

## Browser QA

Chromium / Playwright, deviceScaleFactor 1, visualViewport.scale 1:

- 1512 × 900;
- 1440 × 900;
- 1366 × 768;
- 1280 × 800;
- 1920 × 1080;
- дополнительно 1024 × 800.

Проверена production-сборка через Vite preview. Во всех размерах
scrollWidth равен viewport, нет переполненных текстов, сломанных изображений,
пересечений particles с текстом или ошибок JavaScript/HTTP. Шрифты загружены.
Сравнение с исходным снимком подтвердило неизменность текста, всех URL,
font-size и контейнера при 1512 px.

Реальными действиями проверены hover/press всех 8 CTA и 3 пунктов навигации,
15 последовательных Tab-фокусов, Shift+Tab, Enter, переходы навигации и временных
CTA. Геометрия соседей до/после hover и press совпадает. На 1024 px native
ArrowRight прокручивает экспертов. Отдельно проверены оба логотипа, skip-link,
reduced motion и touch. Telegram URL и mailto сохранены; внешние сервисы для
QA не открывались. Визуально сравнены четыре обновлённые секции и иконки,
в том числе пиксельные края, состояния рамок и native скриншоты при 1512 px.
Новых заметных швов не обнаружено.

`npm run build` успешен: Vite 8.3.3, 12 modules, CSS 31,71 kB
(gzip 7,09 kB), JS 0,85 kB (gzip 0,47 kB). Конфигурация и зависимости сохранены.
Push не выполнялся.
