# RE:CASE — Interactive Micro Motion

Исторический отчёт. Cursor trail и локальная волна заменены в [Particles & Pixel Morph Refinement](./RECASE_Particles_PixelMorph_Refinement.md).

Направление: Balanced / Pixel Motion / Retro Digital. Новых runtime-зависимостей нет.

## Отдельный cursor-follow

По уточнению задачи реализован временный след курсора, а не притяжение существующего декора. `src/motion/cursor-follow.js` создаёт один fixed-слой с пятью переиспользуемыми квадратами 5/7 CSS px, розового, салатового и жёлтого цветов. Он работает в свободном пространстве `main`; Hero сохраняет прежнее отталкивание семи существующих SVG-частиц.

Пиксели появляются при реальном движении мыши за 70 ms. Плавное следование использует интерполяцию с задержкой 45–117 ms; расстояние до курсора ограничено 36 px. После 120 ms покоя след затухает за 180 ms и полностью скрывается. Отображаемые координаты целые, без scale/rotation/blur.

Текст защищается по прямоугольникам фактических строк; карточки и controls — целиком, с запасом 12 px. `pointer-events: none`. DOM-измерения кэшируются, отсутствуют в tick. rAF запускается движением, прекращается после затухания. Scroll, resize, выход из окна, blur, скрытие вкладки и cleanup отменяют цикл. Большой скачок курсора переинициализирует след локально.

## Pixel wave

`src/motion/pixel-wave.js`: «Кому подходит» (`.audience`) и CTA «Готовы попробовать?» (`.participate`), верхний и нижний контуры. Исходные SVG-маски сохранены. Координаты горизонтальных ступеней взяты из существующих mask-paths.

Использован предусмотренный задачей устойчивый вариант: отдельный декоративный слой поверх заливки с пятью короткими сегментами, а не изменение самих масок. Сегменты шириной до 48 px и высотой 14 px перекрывают исходную заливку, обеспечивая непрерывный край. Цвет берётся из фактического background-color маски.

Амплитуда 6 px; промежуточные положения 4/2 px; CSS animation 420 ms, задержки 0–160 ms, общая волна 580 ms. Однократный запуск на pointerenter, повторное наведение после завершения разрешено. Во время hover бесконечных повторов нет. Scroll/resize/выход из viewport/blur отменяют волну. Layout и содержимое секций неподвижны.

## Карточки преимуществ

`src/styles/interactive-motion.css`: четыре `.benefit-card`, border-color → `--color-pink`, individual `translate: 0 -3px`. Существующие токены: 160 ms и cubic-bezier(.2,.7,.2,1). Individual translate компонуется с прежним reveal-transform. Толщина рамки, размеры, сетка, текст и иконки сохранены; фиктивных click/tabindex/cursor:pointer нет.

## Доступность и QA

- Все новые пространственные эффекты доступны только от 1024 px при fine pointer, hover и no-preference. На touch и при reduced-motion временные слои не создаются; движение карточек отключено. При reduced-motion остаётся мгновенная смена цвета рамки.
- Playwright / Chromium: Desktop 1512 × 900, Tablet 744 × 1024, Mobile 390 × 844. Нативная эмуляция reduced-motion при загрузке и при смене предпочтения.
- Проверены медленное/быстрое движение, появление и исчезновение следа, повторный запуск, защита текста; остановка rAF в покое; выход из секции и быстрый scroll; повторный вход и завершение волн; верхний/нижний контуры обеих секций; hover всех четырёх карточек, включая одновременный scroll reveal.
- Размеры, позиции секций, рамки, отступы и шрифты совпали с исходными измерениями; горизонтального overflow нет. Статичные скриншоты обеих пиксельных секций совпали с исходными на всех трёх ширинах. Pending rAF в покое и кадры новых эффектов на touch/reduced — ноль.
- Исправлены слишком широкая защита пустого пространства заголовков и различие оттенка салатовой волны. Последующая проверка цвета и обоих краёв прошла. Видимых разрывов, швов и конфликтов transform не выявлено.
- Кадровая запись следа: медиана 16.7 ms, максимум 32.4 ms. Это локальная браузерная проверка, не универсальный FPS-бенчмарк. В проверке волн layout shifts отсутствовали.
- Hero Boot Sequence, Hero repulsion, Roadmap, Scroll Reveals, кнопки, формы и остальные layout-правила не изменены.

`npm run build`, `node --check`, `git diff --check` — успешно. Git push не выполнялся.
