# RE:CASE — Motion Fix Pass 02

## Причины и исправления

- Прежний временный cursor-follow был удалён при замене локальной волны на Full-Perimeter Morph. Постоянные декоративные частицы сохранились, но эффект появления при движении исчез. `src/motion/cursor-follow.js` возвращает отдельный след, включая Hero: пул из 32 квадратов 4–6 CSS px вместо прежних пяти. Он работает в свободном пространстве Hero и `main`, в том числе розовых/салатовых секций. Существующая система притяжения закреплённых частиц сохранена: 28 дополнительных статичных пикселей на Hero, по 12 на Audience/Format/Participate/Contacts на desktop.
- След появляется за 55 ms, живёт максимум 480 ms, затухает за последние 270 ms. После 110 ms неподвижности курсора начинается возврат к собственной исходной позиции. Spring: stiffness 320, damping 30, максимум смещения 18 px, радиус 140 px. Одновременно создаются до четырёх пикселей каждые 24 ms; активные элементы не переиспользуются до завершения. Координаты целые, используются только translate3d/opacity.
- Защита текста вычисляется по фактическим строкам; карточки, CTA, заголовок Hero и компьютер защищаются целиком с запасом. Измерения кэшируются, отсутствуют в animation tick. Слой `pointer-events: none`; исходные SVG/PNG не дублируются и не изменяются.
- Morph раньше сбрасывался на каждом scroll, после чего ожидал `pointerenter`. Теперь координаты мыши кэшируются, а scroll и IntersectionObserver запускают единственную объединённую проверку `elementFromPoint`. Hover определяется фактическим hit-test, включая вложенные элементы и перекрывающие слои. При неизменном hover анимация не перезапускается; постоянного опроса нет.
- Общая деформация координатных осей заменена перестройкой локальных ступеней: прямые участки исходного SVG разбиваются парными вершинами, которые в hover образуют новые прямоугольные зубцы. Глубина 7 px на Hero, до 10 px у остальных небольших форм, до 14 px у крупных масок; возврат и вход — 280 ms с прежним UI easing. Короткие исходные ступени сохраняются. Текст находится вне декоративной геометрии.
- У SVG-рамок внешняя граница и внутренний вырез получают согласованные ступени с отступом на толщину рамки. При проверке уточнена ширина зубцов для толстых нижних участков, чтобы внутренний вырез не инвертировался. У наклонных стикеров используется исходная локальная система координат. Оригинальная графика восстанавливается при завершении hover-out.

## Охват

18 декоративных поверхностей: Hero title; Audience, Format, Participate, Contacts; две статистические плашки; Registration, Championship, Defence; три рамки Effects; Season Goal; Idea/Team stickers; Process Strip и Partner Banner. Существующий clip-path hover небольших CTA/навигации сохранён.

Четыре `.benefit-card` и три `.partner-card` используют единый hover: подъём 3 px, розовый border, 160 ms и исходный `--ui-easing`. Individual `translate` компонуется с reveal-transform; толщина рамки, сетка, текст, курсор и семантика карточек не меняются.

## Проверка в Chromium / Playwright

- Desktop 1512×900 и 1280×800: все 18 morph-поверхностей, восстановление оригинала, неподвижность текста; медленный/быстрый курсор, появление/затухание следа во всех пяти декоративных сценах, отсутствие перекрытий, сохранение притяжения закреплённых частиц, возвращение и остановка циклов.
- При движении одновременно наблюдалось до 28–32 видимых пикселей следа; Hero — до 32. Без движения временные пиксели полностью скрываются.
- Отдельно проверен scroll-under-cursor у Audience, Participate, Registration, Effects и статистической плашки: курсор устанавливался до скролла, а активация происходила без дальнейшего движения мыши. Проверены быстрый scroll, повторное возвращение и сброс вышедших из viewport поверхностей.
- Tablet 744×1024, Mobile 390×844, а также coarse-pointer при 1512×900: временный след/morph не создаются, карточки не получают пространственный hover, новых animation ticks нет. Статичный декор и responsive layout сохранены, горизонтального overflow нет.
- Нативный reduced-motion при загрузке и переключении: новые движущиеся слои удалены, закреплённые частицы возвращены, подъём карточек отключён. Контент видим.
- Измерения layout совпали с исходными. В изолированном прогоне новых эффектов: layout shifts — 0, long tasks — 0, медиана интервала кадров следа 16,7 ms, p95 17,7 ms. Это локальный результат, не универсальный FPS-бенчмарк. Геометрические выборки промежуточных кадров не обнаружили новых пересечений контуров относительно исходных SVG.
- Проверены все семь карточек, отсутствие движения соседей, очистка модулей/обработчиков/слоёв, открытие формы через CTA, Escape и мобильное меню. Hero/Scroll/Roadmap reveal-модули и их токены не изменены.

`npm run build` успешно: 28 modules, CSS 62,50 kB, JS 33,85 kB (gzip 11,99 kB). `node --check` и `git diff --check` успешно. Runtime-зависимости не добавлены, git push не выполнялся.
